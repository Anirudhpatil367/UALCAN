# RNA-seq Analysis Scripts

This folder contains Python scripts and representative sample files for RNA-seq data-processing and gene-correlation workflows used in the UALCAN research project.

The first workflow included here is for the GEO dataset **GSE201284**. The folder contains:

- One Python analysis script.
- Two small sample input files representing the required raw-data formats.
- Instructions for installing dependencies and running the script.
- The complete structure of the output generated by the script.

The two sample input files are examples of the two required input **file types**. Each file may contain several biological samples because correlation analysis requires at least three paired observations.

## Included Python script

### `GSE201284_all_feature_correlations.py`

This script performs all-gene Pearson correlation analysis for GSE201284. Samples are divided into groups using the clinical and sample information from the metadata file, and gene correlations are calculated separately within each valid group.

The script processes the following metadata features:

- `source_name_ch1`
- `disease_state`
- `preoperative_psa`
- `patient_gleason_score`
- `race`
- `pathologic_stage`
- `age`
- `5_year_disease_status`
- `sample_type`

Important processing rules:

- Missing, unknown, and nonnumeric values are excluded.
- Age values are grouped into decade ranges, such as `50-59` and `60-69`.
- Preoperative PSA values are divided into four quantile-based groups by default.
- Pathologic stages such as T3a and T3b are normalized to T3.
- All genes are analyzed unless a trial subset is selected.
- At least three paired samples are required for a correlation.
- A relationship is retained when the absolute Pearson correlation is greater than `0.30` and the p-value is less than `0.05`.

## Requirements

- Python 3.10 or later
- NumPy
- pandas
- SciPy

Install the required packages:

```bash
pip install numpy pandas scipy
```

## Running the sample analysis

From the `rna_seq/GSE201284` directory, run:

```bash
python scripts/GSE201284_all_feature_correlations.py \
  --tpm raw_files/GSE201284_processed_TPM_sample.txt \
  --metadata raw_files/sample_metadata_sample.tsv \
  --output-root GSE201284_all_results \
  --max-genes 10
```

The `--max-genes 10` option limits the run to the first 10 genes and is recommended for testing the sample files.

## Running the complete analysis

For the complete dataset, place the full input files in `GSE201284/raw_files/` using these names:

```text
GSE201284_processed_TPM.txt
sample_metadata.tsv
```

Then run:

```bash
python scripts/GSE201284_all_feature_correlations.py
```

The script automatically uses the full files from `raw_files/` and writes the results to `GSE201284_all_results/`.

### Gene-expression output

The `genes/` directory contains one JSON file for each analyzed gene. Each file stores that gene's expression values for the samples in the corresponding metadata group.

Example:

```text
GSE201284_all_results/disease_state/cancer/genes/TP53.json
```

### Correlation output

The `features/` directory contains one correlation JSON file for each analyzed gene. Each retained record identifies a correlated gene and includes the Pearson correlation, p-value, and number of paired samples.

Example path:

```text
GSE201284_all_results/disease_state/cancer/features/TP53_feature.json
```

Example record:

```json
{
  "Feature1": "TP53",
  "Feature2": "GENE_B",
  "pc": 0.72,
  "p-value": 0.001,
  "n": 25
}
```

### Run-information files

The output root also contains:

- `run_manifest.tsv`: status of every feature and group processed.
- `run_parameters.json`: input paths and analysis parameters used for the run.
- `run_state.json`: whether the run completed or paused safely.
- `_SUCCESS.json`: created only when the complete requested run finishes successfully.

## Safe stopping and resuming

The script writes output files atomically. If a run is stopped because of an HPC wall-time limit or a termination signal, run the identical command again. Existing completed JSON files are skipped unless `--overwrite` is used.

Example with a 120-minute allocation and a 10-minute shutdown buffer:

```bash
python scripts/GSE201284_all_feature_correlations.py \
  --max-runtime-minutes 120 \
  --shutdown-buffer-minutes 10
```

## Repository rules

- Include the Python script in `scripts/`.
- Include only the two small representative input files in `raw_files/`.
- Do not upload the complete TPM matrix.
- Do not upload generated result directories or large JSON collections.
- Do not upload patient identifiers or confidential research information.
- Validate sample and full-run outputs before using them in publications or downstream systems.
